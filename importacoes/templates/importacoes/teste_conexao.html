Checklist de Diagnóstico
Verificações Básicas:
  • Biblioteca fdb está instalada? pip install fdb
  • IP/Host do servidor está correto?
  • Porta 3050 está acessível? (teste: telnet {{ config.host|default:'IP' }} 3050)
  • Caminho do banco de dados está correto?
  • Usuário e senha estão corretos?
Verificações de Rede:
  • Servidor está acessível? (teste: ping {{ config.host|default:'IP' }})
  • Firewall não está bloqueando a porta 3050?
  • Serviço Firebird está rodando no servidor?
Verificações do Firebird:
  • Firebird Server está instalado no servidor remoto?
  • O arquivo .FDB existe no caminho especificado?
  • O usuário tem permissões de acesso ao banco?
  • Charset está configurado corretamente? (UTF8)
