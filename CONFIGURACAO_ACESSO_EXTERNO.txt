────────────────────────────────────────────────────────────────────────────

────────────────────────────────────────────────────────────────────────────

8. SOLUÇÃO DE PROBLEMAS
================================================================================

PROBLEMA: "Porta 8000 já está em uso"
────────────────────────────────────────────────────────────────────────────
SOLUÇÃO:
for /f "tokens=5" %a in ('netstat -ano ^| findstr :8000') do taskkill /F /PID %a

PROBLEMA: Acesso externo não funciona, mas interno sim
────────────────────────────────────────────────────────────────────────────
CAUSAS POSSÍVEIS:
1. Port forwarding não configurado no roteador
2. DDNS não atualizado (IP externo mudou)
3. ISP bloqueando porta 8000 (tente porta 80 ou 8080)

PROBLEMA: "CSRF verification failed"
────────────────────────────────────────────────────────────────────────────
SOLUÇÃO: Adicione no settings.py:
CSRF_TRUSTED_ORIGINS = [
    'http://folia.dvrdns.org',
    'http://192.168.10.8',
]

PROBLEMA: Imagens/CSS não carregam
────────────────────────────────────────────────────────────────────────────
SOLUÇÃO:
python manage.py collectstatic --noinput

9. SEGURANÇA - RECOMENDAÇÕES

⚠️ PARA PRODUÇÃO, CONSIDERE:
────────────────────────────────────────────────────────────────────────────
1. Usar HTTPS (SSL/TLS)
   - Obtenha certificado SSL (Let's Encrypt gratuito)
   - Configure proxy reverso (Nginx/Apache)

2. Alterar DEBUG para False em produção:
   DEBUG = False

3. Usar senha forte no SECRET_KEY

4. Configurar ALLOWED_HOSTS específicos (remover '*'):
   ALLOWED_HOSTS = ['folia.dvrdns.org', '192.168.10.8']

5. Usar servidor WSGI/ASGI em produção:
   - Gunicorn
   - uWSGI
   - Daphne

6. Backup regular do banco de dados

7. Manter sistema atualizado
