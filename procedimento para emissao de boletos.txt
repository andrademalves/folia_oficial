
# Implementação de Geração de Boletos Caixa Econômica Federal no Módulo Contas a Receber

## Contexto
Preciso implementar funcionalidade completa de geração de boletos da Caixa Econômica Federal integrada ao módulo de contas a receber existente no projeto Django.

## Documentação Técnica de Referência
- Manual CNAB 240 Caixa:  https://www.caixa.gov.br/Downloads/cobranca-caixa/Manual_de_Leiaute_de_Arquivo_Eletronico_CNAB_240.pdf
- Especificações Código de Barras: https://www.caixa.gov.br/Downloads/cobranca-caixa/ESP_COD_BARRAS_SIGCB_COBRANCA_CAIXA.pdf
- Padrão FEBRABAN CNAB 240: https://cmsarquivos.febraban.org.br/Arquivos/documentos/PDF/Layout%20padrao%20CNAB240%20V%2010%2011%20-%2021_08_2023.pdf

**Model:  BeneficiarioCaixa**

- pagador_nome (CharField)

- valor_titulo (DecimalField, max_digits=15, decimal_places=2)
- data_vencimento (DateField)

- desconto_1_data (DateField, opcional)
- mensagem_beneficiario (TextField, opcional)
- instrucoes_caixa (TextField, opcional, ex: códigos de protesto)
- arquivo_remessa (ForeignKey para ArquivoRemessaCNAB240, null=True)
- data_registro (DateTimeField, null=True)
- data_pagamento (DateField, null=True)
- valor_pago (DecimalField, null=True)
- timestamps

- processado (BooleanField, default=False)
- timestamps

**Model: ArquivoRetornoCNAB240**

- data_processamento (DateTimeField)
- quantidade_registros (IntegerField)
- processado (BooleanField)
- erros (TextField, JSON com erros de processamento)
- timestamps

def gerar_boleto(self, beneficiario_id, dados_pagador=None):
    """
    Gera boleto para esta conta a receber
    """
    service = BoletoCaixaService()
    return service.criar_boleto(
        conta_receber_id=self.id,
        beneficiario_id=beneficiario_id,
        dados_pagador=dados_pagador or self._extrair_dados_pagador()
    )
